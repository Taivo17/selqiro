# Selqiro V2 Production Source

This folder is the clean V2 production architecture layer.

The old portal remains available as a working reference.

The V2 skeleton remains available as UX/layout reference.

Production code should be built here with clear separation between:

- shared infrastructure
- entities
- features
- UI components
- data access

Do not copy large old page files into this structure.

Use old code to understand working behavior, then rebuild cleanly.
