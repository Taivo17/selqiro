# My Page Hooks

This folder contains business logic for `app/my-page`.

The goal is to keep `page.tsx` small.

## Hooks

### useMembership
Status: planned

Purpose:
Premium, Business and membership state.

### useProfile
Status: planned

Purpose:
Current profile and identity loading.

### useListings
Status: planned

Purpose:
User listings, search, filters and pagination.

### useLocation
Status: planned

Purpose:
Home location loading and saving.

### useStoreCategories
Status: planned

Purpose:
Store section management.

### useBlockedUsers
Status: planned

Purpose:
Blocked users management.

## Rule

Hooks contain business logic.

Components contain UI.

Page composes components and hooks.
